# Library API

API REST para gestionar libros, socios y préstamos de una biblioteca, con control de disponibilidad,
fechas de devolución y multas por retraso.

## Tecnologías 
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Docker

## Cómo correrlo
1. Levanta la base de datos: 'docker compose up -d'
2. Ejecuta la aplicación: './mvnw spring-boot:run'
